## 0.2.0

- Restricted the supported public API to `CommandChainTimeline` and
  `CommandChainTimelineLocale`.
- Made timeline state, canvas models, painter, and details panel private.

## 0.1.0

- Added an embeddable Flutter timeline for command log snapshots.
- Added executor lanes, zoom, selection, metadata, and failure details.
- Added viewport virtualization for large histories.
- Added English and Russian interface localization.
- Added a realistic English online-store example with JSON file import on
  desktop and web.
