# command_chain_timeline

Интерактивный Flutter-виджет для визуализации и анализа таймлайнов выполнения
команд на основе snapshot из `command_chain_logger`.

Он позволяет детально разобрать, что происходило внутри приложения: какие
команды выполнялись параллельно, какие цепочки стояли в очереди, сколько времени
занял каждый шаг и где произошёл сбой.

![Таймлайн выполнения команд](screenshots/command_timeline.png)

## Зачем это нужно?

Виджет намеренно полностью изолирован от runtime `CommandExecutor`. Он работает
исключительно с готовыми immutable snapshot.

Это открывает сценарии офлайн-отладки:

- **Анализ пользовательских багов:** пользователь экспортирует JSON-лог из
  production-приложения при возникновении ошибки. Разработчик открывает этот
  файл в локальной админ-панели или инструменте разработчика и видит хронологию
  сбоя.
- **Анализ производительности:** timeline помогает находить узкие места при
  инициализации приложения и в тяжёлых бизнес-сценариях.

## Установка

```shell
flutter pub add command_chain_timeline
```

## Использование

Для отрисовки достаточно десериализовать JSON snapshot, полученный из logger,
и передать его в виджет:

```dart
import 'package:command_chain_logger/command_chain_logger.dart';
import 'package:command_chain_timeline/command_chain_timeline.dart';

final snapshot = CommandLogSnapshot.decode(exportedJson);

CommandChainTimeline(snapshot: snapshot);
```

## Ключевые возможности визуализации

- **Группировка по executor:** чёткое разделение потоков выполнения команд по
  экранам и бизнес-модулям, например `AppStartup`, `ProductScreen` и
  `CartScreen`.
- **Визуализация очередей и конкурентности:** отображение lanes, интервалов
  ожидания в очереди и параллельных запусков.
- **Точный хронометраж:** графическое отображение длительности каждой команды
  на общей временной шкале.
- **Инспектор метаданных:** выбор команды открывает панель с ID цепочки, режимом
  выполнения, временем старта, описанием и `details`.
- **Анализ ошибок:** упавшие команды выделяются цветом вместе с termination
  reason и деталями сбоя.
- **Навигация по времени:** поддерживаются zoom и горизонтальный скролл для
  разбора длинных или очень быстрых цепочек.

## Ограничения и зона ответственности

- **Только UI:** пакет отвечает за отрисовку таймлайна и навигацию. Выбор файлов,
  сетевые запросы и интерфейс вокруг timeline остаются на стороне приложения.
  В example JSON можно вставить на любой платформе, а на desktop и web также
  открыть из `.json`-файла.
- **Работа со snapshot:** виджет отображает переданный snapshot и не
  подписывается на изменения живого logger. Для обновления передайте новый
  snapshot, например через `setState` или используемый state manager.

## В планах

- Спроектировать отдельное представление и управление для мобильных устройств.
  Текущий плотный timeline рассчитан на большие экраны и пока неудобен на
  телефонах.
